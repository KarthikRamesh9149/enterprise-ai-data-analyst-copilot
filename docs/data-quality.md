# Data Quality

Validation checks required churn columns, invalid dates, negative revenue, duplicate customer IDs, churn target imbalance, and sensitive column names.

Profiling records row/column counts, inferred types, missingness, unique counts, min/max/mean/std for numeric columns, sample values, duplicate rows, and a quality score.

Warnings are advisory except missing critical columns and unsafe numeric conditions that can degrade downstream analytics/modeling.
