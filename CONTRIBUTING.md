# Contributing

This is a portfolio project, but it is maintained like a production candidate project. Changes should preserve the local-first demo path and the governed AI workflow.

## Development Principles

- Keep the app runnable without paid APIs by preserving mock provider mode.
- Treat generated SQL as untrusted input.
- Keep OpenAI usage optional and bounded.
- Prefer small, reviewable changes.
- Update tests or docs when behavior changes.
- Do not commit secrets, real customer data, local databases, logs, or generated reports.

## Local Verification

Run the relevant checks before opening a pull request:

```bash
cd backend
python -m ruff check .
python -m mypy app
python -m pytest -q
python -m app.scripts.run_evals
python -m app.scripts.smoke

cd ../frontend
npm ci
npm run typecheck
npm run build
npm audit --audit-level=moderate

cd ..
docker compose config
```

## Pull Request Expectations

Pull requests should include:

- A short description of the user-facing or engineering change.
- Testing evidence.
- Any security, governance, or AI-provider implications.
- Screenshots for frontend changes.

## Demo Data

Use only synthetic data generated by:

```bash
python scripts/generate_demo_data.py
```
